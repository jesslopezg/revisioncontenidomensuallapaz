# Revisión de contenido · Funeraria La Paz

Presentación interactiva de las propuestas de noviembre de 2026 para revisión del cliente.

La página incluye campos para aprobar cada pieza o solicitar ajustes. Los comentarios se conservan localmente en el navegador hasta que el revisor los envíe mediante su aplicación de correo o descargue una copia.

Despliegue: GitHub Pages, rama `main`, carpeta `/ (root)`.
